# update-me

Update linux systems easy.

## Install from source
```bash
git clone https://github.com/Noticxs/update-me.git
cd update-me

cargo build --release
cargo install --path .
```


## Install with cargo (not done yet btw)
```bash
cargo install update-me
```

This was made mainly for my system, so if it doesn't work as intended, create a PR.
I can't guarantee I'll fix it, but I'll look into it.
